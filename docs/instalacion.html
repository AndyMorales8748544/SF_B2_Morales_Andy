Instalación y ejecución local

Esta sección describe los pasos necesarios para descargar y ejecutar la aplicación SF - Registro de Usuarios.

1. Requisitos previos

  • Git instalado.
  • Navegador web actualizado.
  • Node.js 24 para ejecutar las pruebas automatizadas.

2. Clonar el repositorio

Ejecutar el siguiente comando:

git clone https://github.com/AndyMorales8748544/SF_B2_Morales_Andy.git

3. Ingresar al proyecto

cd SF_B2_Morales_Andy

4. Ejecutar la aplicación

Abrir el archivo index.html en un navegador web. La aplicación no requiere instalar dependencias adicionales para su funcionamiento.

5. Verificar el funcionamiento

  • Ingresar un nombre válido y comprobar que se muestre un mensaje de registro exitoso.
  • Dejar el nombre vacío y comprobar que se muestre un mensaje de error.

6. Ejecutar pruebas automatizadas

Desde la carpeta principal del proyecto:

node --check script.js
node --test tests/registro.test.js

Resultado esperado: verificación de sintaxis sin errores y dos pruebas automatizadas aprobadas.
