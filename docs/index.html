Objetivo del proyecto

Desarrollar una aplicación web básica para registrar usuarios mediante un formulario, aplicando validaciones de entrada y mostrando mensajes de confirmación o error.

Alcance del proyecto

La aplicación permite ingresar el nombre de un usuario, validar que el campo no esté vacío y mostrar el resultado del registro. Se desarrolla utilizando HTML, CSS y JavaScript.

El proyecto también contempla control de versiones con Git y GitHub, pruebas automatizadas con Node.js, integración continua con GitHub Actions, documentación técnica y ejecución mediante Docker.
